+# Bots 工作区重设计
+## 目标与设计依据
+在当前 `agent` 分支，将依附页面的单 Bot 面板升级为常驻 Bots 工作区：侧边栏底部提供 Bots 入口，管理多个 Bot，同一 Bot 可以创建多个独立会话，不同会话可并排显示并同时运行。用户已明确选择“多个聊天面板并排显示，并行运行”。
+参考 OpenBot 的三项设计，而非移植其整套服务：
+* Bot 是持久的角色与能力配置，会话与 Bot 分离；同一 Bot 的不同会话不共享对话历史。[Coworkers](https://github.com/CopilotKit/OpenBot/blob/main/docs/coworkers.md)
+* 操作通过统一权限边界，角色描述不等于工具权限。[Architecture](https://github.com/CopilotKit/OpenBot/blob/main/docs/architecture.md)
+* 每条会话同一时刻只允许一个运行，不同会话独立调度。[Thread lock](https://github.com/CopilotKit/OpenBot/blob/main/toolkit/src/copilotkit/thread-lock.ts)
+首版继续使用 SwiftUI/AppKit、现有模型客户端、MCP、Skills 和 A2UI，不引入 React、PostgreSQL、CopilotKit Intelligence、Docker 或 AG-UI 服务依赖。远程 AG-UI Agent 接入不属于此次范围。
+## 当前实现与必须改变的边界
+* `Sources/Search/Browser.swift:349` 附近分别保存单例页面 Bot、Chat Tab Bot 和临时历史；`Sources/Search/Bot.swift (1646-1736)` 打开/关闭页面面板会停止当前运行。
+* `Sources/Search/Bot.swift:1595` 的标签解析依赖 `Front.shared.browser`，`Bot.swift:849` 每次观察可能重新读取前台页。并行会话必须绑定明确的窗口和页面上下文，不能随用户切窗改变操作目标。
+* `Sources/Search/ChatTab.swift:251` 为每个聊天标签创建运行实例，但关闭标签即停止，且聊天不持久化。新会话的生命周期不能归属于某个 View 或浏览器标签。
+* `Sources/Search/Side.swift (512-559)` 是侧边栏底部与剩余空间计算；`Sources/Search/App.swift:428` 附近负责主内容区域选择。
+* `Sources/Search/Chores.swift:80` 和 `Chores.swift:186` 依赖前台 `botting` 调度；迁移后不能让定时任务覆盖手动会话。
+## 交互方案
+### Bots 入口与 Bot 列表
+* 在浏览器侧边栏底部、现有工具图标行上方增加整行 `Bots` 入口，带运行数量和待处理提示；入口始终存在，未配置模型时引导配置，而不是隐藏。
+* 点击进入页面右侧的 Bots 工作区，不创建普通网页标签；页面留在左边照常使用，原网页选择不丢。再次点击入口或面板自己的 × 收起来，会话在后台照常运行。
+* 工作区与页面之间的分界线可拖拽调整宽度（默认 420，300–900），双击回到默认宽度，宽度跨启动保留；窄窗口下页面保底 280pt，面板保底 300pt。窗口本身过窄时面板先让位给页面，不把页面压成一条。
+* 顶部标签布局及侧边栏折叠时，通过菜单和相应工具入口仍可到达 Bots，不依赖永久展开侧边栏。
+* Bot 列表提供搜索、新建、编辑、复制、置顶、归档与删除。条目显示头像、名称、用途、运行中/需要处理数量，优先显示需要处理的 Bot。
+* 默认迁移生成“通用助手”，沿用现有提供方、模型、思考深度和步数；不会创建缺少实际配置的示例机器人。
+### 多会话与并排聊天
+* 工作区内使用一列可收起的 Bot/会话导航，避免同时堆叠多列列表挤压聊天宽度。会话支持新建、重命名、搜索、归档和删除。
+* 单击打开会话。**面板一次只显示一个会话**（用户决定，取代首版的 1–4 窗格并排）：窗格占据面板整宽，页面在旁边照常使用；会话列表就是切换方式，不再有“并排打开”。多会话仍各自独立调度、并行运行，只是不并排看。面板再窄也不横向滚动：对话以面板宽度换行，底部“AI — may be wrong · 页面”那行始终独占自己的几行，不会被横向滚动条压住。
+* 会话**永远不横向滚动**：面板多窄，对话就占多宽、文字自行折行；过去的“窄于最小宽度就横向滚动”一旦触发，横向滚动条会压在对话底部那句“AI — may be wrong · 页面”上。会话底部那行属于它自己，任何滚动条、边框或控件都不得覆盖。
+* 会话条目用状态点表示运行状态：等待你处理时琥珀色（与门的点一致）、运行中橙色、失败/被中断红色、空闲灰色，不再显示状态字样。列表行（Bot 列表与会话列表）的 hover 样式参照侧边栏标签列表：悬停灰色背景、快速过渡动画、文字变色；正在显示的会话行悬停时显示关闭叉，关闭窗格但不停运行（与窗格右上角的叉语义一致）。
+* 会话窗格右上角的**全屏按钮**让对话占满整个 stage（页面让位，不是被盖住），再按一次或 Escape 回到“页面 | 面板”并排，页面宽度原样恢复。全屏只是面板的显示方式，收起面板会一并退出全屏。
+* 每个窗格独立拥有消息、输入草稿、滚动位置、流式回复、思考展示、A2UI 卡片、操作结果、审批和 Stop。焦点与快捷键只作用于当前窗格。
+* 关闭窗格、离开 Bots 或选择另一 Bot 都不会停止后台会话；Stop、归档正在运行的会话、删除或应用退出才明确结束运行。归档/删除活动会话需要确认。
+* 同一会话不会在两个窗格中重复创建运行实例，再次打开时聚焦已有窗格；多窗口查看时也共用同一会话运行。
+## 数据与运行模型
+### 三层结构
+* `BotProfile`：稳定 UUID、名称、头像、角色说明、提供方/模型、思考深度、步数、允许的 MCP 工具与 Skills、是否允许浏览器/命令/剪贴板/历史/记忆等能力，以及置顶/归档状态。密钥继续保留在既有凭据系统，不复制进 Bot 配置。
+* `BotSession`：稳定 UUID、所属 Bot、标题、消息与事件、草稿、明确的浏览器上下文、更新时间及最近运行状态。会话历史互不共享；Bot 记忆按 Bot 隔离。
+* `BotRun`：一次用户请求或任务触发的执行，拥有 runID、配置快照、取消句柄、审批、进程与页面占用。状态包括 queued、running、waitingApproval、waitingHuman、completed、failed、cancelled、interrupted。
+### 所有权与并行
+* 新增应用级会话注册表/运行协调器，独立于页面和 SwiftUI View；Browser 只保存工作区导航、窗格布局及当前焦点。
+* 每会话同一时间一个 Run，重复提交时不并发追加到同一历史；草稿保留，按钮明确显示忙碌状态。
+* 默认允许 4 个交互 Run 并发，超出时排队并可单独取消；内置本地模型默认串行，以免同一模型进程争抢资源。外部提供方的各条流独立取消。
+* Run 启动时冻结 Bot 配置及模型目标；运行期间修改配置不改变已发出的请求或放宽正在等待的审批。下一 Run 使用新配置。
+* 所有异步结果通过 sessionID/runID 和代次校验；已停止运行的迟到回调不能追加消息、继续工具调用或改变另一个会话状态。
+## 浏览器目标与权限
+* 新会话默认不自动读取全部网页。用户明确绑定一个网页、选择一组标签，或给会话创建自己的后台工作页；纯聊天不要求网页存在。
+* 上下文记录所属窗口/Space 和稳定标签 ID。模型展示的短 ID 映射归该会话，不再通过当前前台窗口隐式查找。页面关闭、切换 Space 或隐私属性改变时重新验证目标，不能自动换到另一页。
+* 同一页面的快照到动作使用独占占用：不同页面可并行，同一页面被另一会话操作时显示等待，不允许两个会话覆盖快照引用。等待审批仍标识页面所有者；取消、超时、人工接管或结束释放占用，恢复前重新观察页面。
+* 执行动作前校验页面身份与快照有效性；页面已变化则重新观察，必要时重新审批，不把旧 `@ref` 当成新页面上的同号元素。
+* 所有入口，包括旧页面 Bot、MCP 工具、Skills、命令和定时任务，执行时都检查 Bot 能力授权；仅在 prompt 中隐藏工具不算限制。Auto 不能开启未授权能力。
+* 保留已有规则：私密网页只允许本地模型且会话不落盘；网页外操作默认审批；关闭用户标签始终审批；无人值守任务不允许执行网页外操作。审批带 sessionID/runID/动作身份，不能串到旁边窗格。
+* 首版隔离的是会话历史、目标页面和授权，不提供 OpenBot 的独立容器/文件系统。后台工作页默认沿用所选 Space 的登录态，界面明确提示；每 Bot 独立 Cookie/Profile 可作为后续能力。
+## 持久化与恢复
+* 通过 `Store.file` 保存版本化 Bot 配置索引及每会话独立 JSON，沿用后台串行写入、原子替换和损坏文件隔离；目录仅本人可读写，会话文件权限 0600。
+* 保存用户消息、完整回答、操作结果、会话元数据、输入草稿及可恢复的卡片协议数据；原始思考内容和密钥默认不落盘。ViewModel/Task/Process/闭包不是存档内容。
+* 保留可读的中断回复并标记未完成，不把它伪装为已完成的模型消息。恢复聊天历史不恢复操作权限。
+* 重启时 running、queued 和待审批 Run 统一转 interrupted，不自动重放命令、点击或批准；用户继续时生成新 Run 并重新观察页面。
+* Bot 删除采用归档/墓碑方式，历史仍可查看，不能继续运行；硬删除历史是单独确认的动作。清空一个会话不再调用全局 `Bot.forget()` 删除所有 Bot 的记忆。
+## 兼容迁移
+* 把现有 AI 设置作为默认 Bot 的初值；既有模型密钥、MCP 配置、Skills 文件保持原位。旧全局 Bot 记忆只迁入默认 Bot，一次性迁移成功后记录版本。
+* “New Agent Chat”和页面 Bot 快捷入口都转向新会话服务：前者新建普通会话，后者绑定明确网页。不再维护第二套无持久化的聊天运行系统。
+* 将现有 `Bot` 运行循环拆分为可由会话服务持有的执行核心，保留 Markdown、流式思考、A2UI、人工接管和工具结果展示；旧 BotPanel/ChatStage 收敛到统一聊天窗格，并以 release 构建验证，避免既有 `-Osize` 跨视图渲染问题回归。
+* 定时任务绑定 Bot 身份，每次触发创建独立任务会话/Run，不复用前台 `botting`。已保存 running 任务恢复为中断，人工接管单独记录，不因周期重排丢失本轮结果。
+* 调整 `App.swift` 的 stage、地址框、焦点归还、Split View 和快捷键路径，使 Bots 与网页互斥展示；窗口里关闭一个聊天窗格只移除显示，不删除会话或取消后台运行。
+## 实施顺序与文件边界
+先固定数据模型、持久化和上下文/权限契约，再改运行所有权与调度，最后接入工作区、迁移旧入口与任务。这些步骤共享运行循环和 Browser 状态，本轮由同一实现流程顺序集成，不并行修改耦合文件。

+* 新增 `BotContext.swift`、`BotPermissions.swift`，重构 `Bot.swift`：明确页面解析、能力校验、占用、每 Run 状态与取消。
+* 新增 `BotsWorkspace.swift`、`BotChatView.swift`：Bot 列表、会话导航、并排布局与统一聊天窗格。

+        try queue.sync {

+        let data = try encoder.encode(value)

+        var messages: [AIMessage] = []
+        var cards: Data?
+    }
+
+    let id: UUID
+    let profileID: UUID
+    @Published var title: String
+    @Published var archived: Bool
+    @Published private(set) var updated: Date
+    let runtime: Bot
+    let context: BotContext
+    private(set) var ephemeral: Bool
+    private var relay: AnyCancellable?
+    var changed: (() -> Void)?
+    var stateChanged: (() -> Void)?
+    private var lastState = ""
+    private var saving: Task<Void, Never>?
+
+    init(record: Record, profile: BotProfile, context: BotContext) {
+        id = record.id
+        profileID = record.profileID
+        title = record.title
+        archived = record.archived
+        updated = record.updated
+        self.context = context
+        ephemeral = context.privatePages
+        runtime = Bot(session: record.id, profile: profile, context: context)
+        runtime.restore(events: record.events, messages: record.messages, cards: record.cards)
+        runtime.draft = record.draft
+        runtime.runState = record.state.active ? .interrupted : record.state
+        relay = runtime.objectWillChange.sink { [weak self] _ in
+            // Published sends before the mutation. Snapshot after the build's
+            // changes, and coalesce streaming tokens into a single disk write.
+            Task { @MainActor [weak self] in self?.scheduleSave() }
+        }
+    }
+
+    func scheduleSave() {
+        objectWillChange.send()
+        let state = "\(runtime.runState.rawValue):\(runtime.busy):\(runtime.pending?.id.uuidString ?? "")"
+        if state != lastState { lastState = state; stateChanged?() }
+        updated = Date()
+        saving?.cancel()
+        saving = Task { @MainActor [weak self] in
+            try? await Task.sleep(nanoseconds: 250_000_000)
+            guard !Task.isCancelled else { return }
+            self?.changed?()
+        }
+    }
+
+    func snapshot() -> Record {
+        if context.privatePages { ephemeral = true }
+        let held = runtime.hold()
+        var events = held.events.filter { $0.kind != .think }
+        if let draft = runtime.drafting, !draft.words.isEmpty {
+            events.append(Bot.Event(kind: .trouble, words: "Unfinished reply: " + draft.words, act: nil))
+        }
+        return Record(id: id, profileID: profileID, title: title, archived: archived,
+                      updated: updated, draft: runtime.draft, state: runtime.runState,
+                      events: Array(events.suffix(1000)), messages: held.messages,
+                      cards: runtime.cardArchive)
+    }
+
+    func detach() {
+        changed = nil
+        stateChanged = nil
+        saving?.cancel()
+        relay?.cancel()
+        runtime.stop()
+    }
+}

+Build first. Uses bot_panel's isolated probe lifecycle, never the user's

+class Model(BaseHTTPRequestHandler):
+    protocol_version = "HTTP/1.1"

+    def do_POST(self):
+        global active, maximum
+        body = json.loads(self.rfile.read(int(self.headers.get("Content-Length", 0))))
+        users = "\n".join(m.get("content", "") for m in body.get("messages", []) if m.get("role") == "user")
+        marker = next((m for m in ["APPROVE_ALPHA", "APPROVE_BETA", "CONVERSATION_ALPHA", "CONVERSATION_BETA"] if m in users), "UNKNOWN")
+        with lock:
+            requests.append((marker, body))
+            active += 1
+            maximum = max(maximum, active)
+        acted = any('"act"' in m.get("content", "") for m in body.get("messages", []) if m.get("role") == "assistant")
+        if marker.startswith("APPROVE_") and not acted:
+            reply = {"act": {"verb": "fill", "target": "css=#first", "text": marker}}
+        else:
+            reply = {"answer": "Answer for " + marker}
+        text = json.dumps(reply)
+        pieces = [text[:12], text[12:24], text[24:]]
+        self.send_response(200)
+        self.send_header("Content-Type", "text/event-stream")
+        self.send_header("Transfer-Encoding", "chunked")
+        self.end_headers()
+        try:
+            for piece in pieces:
+                time.sleep(0.35)
+                data = ("data: " + json.dumps({"choices": [{"delta": {"content": piece}}]}) + "\n\n").encode()
+                self.wfile.write(f"{len(data):X}\r\n".encode() + data + b"\r\n")
+                self.wfile.flush()
+            done = b"data: [DONE]\n\n"
+            self.wfile.write(f"{len(done):X}\r\n".encode() + done + b"\r\n0\r\n\r\n")
+            self.wfile.flush()
+        except (BrokenPipeError, ConnectionResetError):

+        finally:

+def wait_for(session, predicate, timeout=20):

+def settle(predicate, timeout=20):
+    """Wait for the split's own geometry: a width is laid out on the pass
+    after it is set, as it is on screen, so one reading proves nothing."""

+def png_rows(path):
+    """A picture's rows of pixels, unfiltered: one bytearray a row, four
+    bytes a pixel. The usual five PNG filters, undone (see chat_tab's
+    bands)."""
+    import struct, zlib
+    with open(path, "rb") as f:
+        png = f.read()
+    assert png[:8] == b"\x89PNG\r\n\x1a\n", "not a PNG"
+    pos, width, height, idat = 8, 0, 0, b""
+    while pos < len(png):
+        length = struct.unpack(">I", png[pos:pos + 4])[0]
+        kind = png[pos + 4:pos + 8]
+        if kind == b"IHDR":
+            width, height = struct.unpack(">II", png[pos + 8:pos + 16])
+        elif kind == b"IDAT":
+            idat += png[pos + 8:pos + 8 + length]
+        pos += 12 + length
+    raw = zlib.decompress(idat)
+    stride = width * 4 + 1
+
+    def paeth(a, b, c):
+        p = a + b - c
+        pa, pb, pc = abs(p - a), abs(p - b), abs(p - c)
+        if pa <= pb and pa <= pc: return a
+        if pb <= pc: return b
+        return c
+
+    prev = bytearray(width * 4)
+    rows = []
+    for y in range(height):
+        start = y * stride
+        f = raw[start]
+        line = bytearray(raw[start + 1:start + stride])
+        for i in range(len(line)):
+            left = line[i - 4] if i >= 4 else 0
+            up = prev[i]
+            corner = prev[i - 4] if i >= 4 else 0
+            if f == 1: line[i] = (line[i] + left) & 0xFF
+            elif f == 2: line[i] = (line[i] + up) & 0xFF
+            elif f == 3: line[i] = (line[i] + (left + up) // 2) & 0xFF
+            elif f == 4: line[i] = (line[i] + paeth(left, up, corner)) & 0xFF
+        rows.append(line)
+        prev = line
+    return rows, width, height
+

+def png_ground(rows, width, height):
+    """The colour most of the picture is: the ground the words are drawn
+    on, whatever the theme puts there."""
+    import collections
+    seen = collections.Counter()
+    for y in range(0, height, 7):
+        line = rows[y]
+        for x in range(0, width, 7):
+            seen[(line[x * 4], line[x * 4 + 1], line[x * 4 + 2])] += 1
+    return seen.most_common(1)[0][0]

+def inked(rows, ground, x0, x1, y):
+    """Whether a row of the picture carries ink across the conversation's
+    width: words, a scroller, a rule. Ink is anything that isn't the
+    ground — a scroller's trough is drawn over the ground, so it counts."""
+    line = rows[y]
+    count = 0
+    for x in range(x0, x1):
+        r, g, b = line[x * 4], line[x * 4 + 1], line[x * 4 + 2]
+        if abs(r - ground[0]) + abs(g - ground[1]) + abs(b - ground[2]) > 12:
+            count += 1
+    return count >= 3
+

+def band_over(path):
+    """How many rows of ink lie just over the foot line, in one solid band
+    — the scroller that used to be drawn there. A band is a run of rows
+    each inked across the conversation's width, ended by a stretch of bare
+    ground."""
+    rows, width, height = png_rows(path)
+    ground = png_ground(rows, width, height)
+    # Words are drawn down the left; the conversation runs to the panel's
+    # edge, and it is the whole width a band spans.
+    x0, x1 = int(width * 0.25), width - 3
+    foot = foot_line(path)
+    if not foot:
+        return 0
+    solid = 0
+    for y in range(foot[0] - 1, max(-1, foot[0] - 60), -1):
+        if inked(rows, ground, x0, x1, y):
+            solid += 1
+        else:
+            break
+    # One row of near-ink is the bottom of a letter; a band is what a
+    # scroller draws.
+    return solid if solid >= 3 else 0
+
+
+def foot_covered(path):
+    """The most of the foot line's width any one row of it covers, 0 to 1.
+    A line of small faint words covers a fifth of it at most; a scroller's
+    trough drawn over the line covers all of it. What the bug looked like,
+    said as a number."""
+    rows, width, height = png_rows(path)
+    ground = png_ground(rows, width, height)
+    x0, x1 = int(width * 0.25), width - 3
+    foot = foot_line(path)
+    if not foot:
+        return 1.0
+    span = x1 - x0
+    most = 0.0
+    for y in range(foot[0], foot[1] + 1):
+        line = rows[y]
+        n = sum(1 for x in range(x0, x1)
+                if abs(line[x * 4] - ground[0]) + abs(line[x * 4 + 1] - ground[1])
+                 + abs(line[x * 4 + 2] - ground[2]) > 12)
+        most = max(most, n / span)
+    return most
+
+
+def foot_line(path):
+    """The foot line's own rows: the lowest band of words in the picture
+    that is not the bottom edge's own divider — where the line that says
+    the AI may be wrong is drawn. Returns (top, bottom, rows tall), or
+    None when no such band stands."""
+    rows, width, height = png_rows(path)
+    ground = png_ground(rows, width, height)
+    x0, x1 = int(width * 0.25), width - 3
+    bands, in_band, top = [], False, 0
+    for y in range(max(0, int(height * 0.5)), height):
+        here = inked(rows, ground, x0, x1, y)
+        if here and not in_band:
+            in_band, top = True, y
+        elif not here and in_band:
+            bands.append((top, y - 1))
+            in_band = False
+    if in_band:
+        bands.append((top, height - 1))
+    # The foot line is a band of small words near the bottom, and the
+    # lowest one that isn't the picture's own edge.
+    bands = [b for b in bands if b[1] < height - 4 and b[1] - b[0] >= 2]
+    if not bands:
+        return None
+    bottom = bands[-1]
+    return (bottom[0], bottom[1], bottom[1] - bottom[0] + 1)
